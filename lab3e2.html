Exercise 2

Part A: Message JSON

The message information can be represented as one JSON object containing name/value pairs. 

{
  "to": "Alex",
  "from": "Jordan",
  "heading": "Reminder",
  "body": "Don't forget our meeting tomorrow."
}

Part B: Book Collection JSON

The books can be stored in an array. Each item in the array is a separate book object. 

{
  "books": [
    {
      "title": "Web Development Basics",
      "author": "Maya Lee",
      "price": 29.99
    },
    {
      "title": "Modern JavaScript",
      "author": "Daniel Kim",
      "price": 34.50
    },
    {
      "title": "Understanding JSON",
      "author": "Sofia Patel",
      "price": 24.95
    }
  ]
}

Validation

I checked the JSON structure to make sure the property names and text values use double quotation marks, commas are placed correctly, and the objects and arrays are properly opened and closed.
