Exercise 1

Main Structure

The Open Library JSON data is organized as one main JSON object. Inside the object are many key/value pairs that describe the book Fantastic Mr. Fox.

Main Keys

Some of the main keys include title, authors, publish_date, publishers, covers, languages, number_of_pages, isbn_10, isbn_13, and first_sentence.

Simple Values

Some values are simple text or numbers. For example, the title is stored as text and the number of pages is stored as a number.

Name/Value Pair:
"title": "Fantastic Mr. Fox"
Number Value:
"number_of_pages": 96

Objects

Some values contain another object. An object contains its own set of key/value pairs.

Object Example:
"type": {
  "key": "/type/edition"
}

Arrays

Arrays are used when a key can contain more than one value. For example, the covers key contains several cover identification numbers.

Array Example:
"covers": [15152634, 8739161, -1]

Nested Structures

The JSON also contains nested structures. This means that an array can contain objects, or an object can contain other key/value pairs.

Nested Array and Object:
"authors": [
  {
    "key": "/authors/OL34184A"
  }
]

Another Nested Object

"first_sentence": {
  "type": "/type/text",
  "value": "Down in the valley there were three farms."
}

Overall Organization

Overall, the JSON is organized like a record for a book. The main object contains information about the book, such as its title, publication date, authors, ISBN numbers, page count, and other identifying information. Arrays are used when there can be several values, while nested objects are used when a value needs additional information.
