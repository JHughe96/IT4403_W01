Lab 2 - jQuery

Exercise 1:

Overview: The examples showed that jQuery does not replace normal JavaScript concepts like variables, calculations, loops, and functions. It mainly makes it easier to work with webpage elements, events, output, and CSS. Calculations and Output: Traditional JavaScript used methods such as document.write() and getElementById(). The jQuery version used shorter commands such as $("#result").html() and .append() to display results. Loops: The for loop worked almost the same in both versions. The main difference was that jQuery used .append() to add the loop output to the webpage. Functions: Functions were written almost the same way in JavaScript and jQuery. jQuery mainly shortened the code used to display or change webpage content. DOM Access and Manipulation: JavaScript used document.getElementById(), innerText, and innerHTML. jQuery used shorter methods such as $("#id"), .text(), .html(), and .attr(). Click Events: Traditional JavaScript often used onclick in the HTML. jQuery used .click(function(){...}) so the event code could stay in the JavaScript file. CSS Manipulation: JavaScript changed styles with the .style property. jQuery used the .css() method, which made the code shorter and easier to read. Main Differences Observed

    • Element selection: jQuery uses short CSS-style selectors such as $("#result") instead of document.getElementById("result").
    • DOM manipulation: jQuery uses methods like .text(), .html(), .val(), and .attr().
    • Event handling: jQuery can connect click events directly in the script with .click().
    • Output generation: jQuery can place or add output with .html() and .append().
    • CSS manipulation: jQuery uses .css() instead of changing each .style property.
    • Code length and structure: jQuery usually requires less code and can be easier to read.
Conclusion: The biggest difference is that jQuery makes common webpage tasks shorter and simpler. The actual programming logic usually stays the same, but selecting elements, handling clicks, changing HTML, and changing CSS can be done with less code.
